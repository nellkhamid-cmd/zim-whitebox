# ЖК «ЗИМ Галерея», Дом Кино: мини-лендинг предчистовой отделки

Статичный сайт: HTML + CSS + JS, без сборки и внешних библиотек. Открывается двойным щелчком по `index.html` (для file:// шрифты встроены в `assets/css/fonts-local.css`). Дизайн следует `catalog.zim-galereya.ru`. Планировки на страницу не выводятся.

| Блок | Якорь | Что на нём |
|---|---|---|
| Первый экран | `#main` | Квартиры бизнес-класса с отделкой White Box\* в ЖК «ЗИМ Галерея», кнопка каталога |
| Условия | `#условия` | Первый взнос 50%, отсрочка до 01.06.2027 |
| Форма каталога | `#форма` | Имя, телефон, почта, два согласия |
| Что входит | `#отделка` | Состав отделки, фото квартиры |
| Дом Кино | `#дом` | Лобби, паркинг, двор |
| Локация | `#локация` | Окружение и карта |
| Запись на показ | `#показ` | Имя, телефон, два согласия |

Быстрые ссылки Директа: «Что входит в отделку» `#отделка`, «Квартиры в Доме Кино» и «Квартиры с видом на Волгу» `#форма` (отдельного блока квартир на странице нет), «Условия покупки» `#условия`, «Получить каталог» `#форма`, «Записаться на показ» `#показ`.

## Перед запуском

1. **Обработчик заявок.** В начале `assets/js/main.js`, объект `CONFIG`: задать `FORM_ENDPOINT`. Пока он пуст, заявка никуда не уходит, хотя посетитель видит «Заявка принята».
2. **Метрика.** Там же `YM_COUNTER`, код счётчика добавить в `index.html`. Цели: `whitebox_catalog`, `whitebox_show`.
3. **Индексация.** Убрать `<meta name="robots" content="noindex, nofollow">` из `index.html`.
4. **CORS.** Заявка уходит как `POST` с `Content-Type: application/json`. Обработчик на другом домене должен отвечать на `OPTIONS` и разрешать домен сайта.
5. **Превью в мессенджерах.** В `og:image` указать полный адрес и формат JPG или PNG 1200 × 630.
6. **Документы.** Согласия и политика ведут на `catalog.zim-galereya.ru`, юрлицо взято с прошлых лендингов: подтвердить у юриста, что подходят этому домену.
7. **Шрифт Quincy CF.** Коммерческий, лицензии на веб-использование в материалах нет: подтвердить. Jost свободный (`Jost-OFL.txt`).

## Настройка

- Карта района собрана скиллом brand-map из данных OpenStreetMap: `assets/img/map.svg`, `assets/js/map.js`, `assets/css/map.css`. Подпись «© участники OpenStreetMap» обязательна по лицензии, удалять нельзя.
- В заявку уходят: `name`, `phone`, `email` (форма каталога), согласия, `utm_*`, `offer`, `request` (Каталог или Показ), `page`, `submitted_at`.
- На хостинг не нужен `README.md`.
- При смене `main.css` или `main.js` обновляйте метку `?v=` в `index.html`.
- Всё движение отключается при `prefers-reduced-motion`.
